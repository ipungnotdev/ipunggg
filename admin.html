⚙️ Pengaturan API

Konfigurasi koneksi ke rumahotp.io

🔑 API Key RumahOTP
Dapatkan API Key dari dashboard rumahotp.io → Profile → API Key
📚 Dokumentasi API

API rumahotp.io menggunakan header x-apikey untuk autentikasi.

// Base URL
https://www.rumahotp.io/api

// Endpoints utama:
GET /v1/user/balance — Cek saldo
GET /v2/services — List aplikasi
GET /v2/countries?service_id=ID — List negara
GET /v2/orders?number_id=&provider_id=&operator_id= — Beli nomor
GET /v1/orders/get_status?order_id= — Cek OTP
GET /v1/orders/set_status?order_id=&status= — Ubah status
